# Участник №2 — модель машинного обучения

## Назначение

Разработка модели машинного обучения для предсказания
индекса селективности SI химических соединений
против вируса VACV.

## Формула

SI = CC50 / IC50

- IC50 — концентрация, подавляющая 50% активности вируса.
- CC50 — концентрация, вызывающая гибель 50% клеток.
- SI — индекс селективности.

## Используемые технологии

- Python
- RDKit
- NumPy
- Pandas
- Scikit-learn
- Joblib

## Признаки молекул

1. Morgan Fingerprints
2. Molecular Weight
3. LogP
4. TPSA
5. Ring Count
6. NumHDonors
7. NumHAcceptors

## Алгоритмы

- Random Forest Regressor
- Extra Trees Regressor

Алгоритмы сравниваются с помощью кросс-валидации.
Выбирается модель с наименьшей средней MAE.

## Подготовка данных

Файл data/processed_data.csv должен содержать:

- smiles
- IC50
- CC50

IC50 и CC50 должны быть положительными числами
в одинаковых единицах измерения.

SI рассчитывается программой автоматически.

## Установка

pip install -r requirements.txt

## Обучение

python train.py

## Предсказание

python predict.py --input data/new_compounds.csv --output results/predictions.csv

## Результаты

После обучения создаются:

- models/si_model.joblib
- results/training_report.json
- results/test_predictions.csv

## Ограничения

Модель является исследовательским прототипом.
Предсказания не заменяют лабораторные исследования.

Качество модели зависит от объёма, качества
и сопоставимости экспериментальных данных.




# Участник №4 — демонстрационное приложение

## Назначение

Веб-приложение для демонстрации работы модели, которая предсказывает индекс селективности SI химических соединений против вируса VACV (вируса осповакцины). Пользователь вводит SMILES молекулы и сразу видит её структуру, прогноз SI и основные химические характеристики.

Приложение не содержит собственной модели. Оно подключается к модели участника №2 и работает с любой молекулой, заданной только SMILES-записью. Столбцы `CC50_uM` и `IC50_uM_VACV` не используются.

## Возможности

1. **Вкладка «Прогноз».** Ввод SMILES, кнопки с примерами молекул, изображение структуры, прогноз SI и log10(SI), статус «перспективно / низкая селективность», таблица дескрипторов.
2. **Вкладка «Пакетный CSV».** Загрузка CSV со столбцом `smiles` (до 500 молекул), таблица прогнозов, скачивание результата.
3. **Вкладка «О модели».** Название лучшей модели и целевая переменная, таблица кросс-валидации, график «предсказано vs реальное» и важность признаков (если есть данные для них).

## Используемые технологии

* Streamlit

* Matplotlib

## Как приложение связано с моделью

Приложению нужна одна функция `predict(smiles, package)`, которая возвращает словарь:

| Поле | Значение |
|------|----------|
| `valid` | корректна ли SMILES-запись |
| `SI`, `log10_SI` | прогноз индекса селективности |
| `std_SI` | разброс предсказаний деревьев ансамбля (для Random Forest и Extra Trees) |
| `active` | `SI >= 10` |
| `descriptors` | молекулярная масса, LogP, TPSA, число атомов, связей, колец и т. д. |
| `is_mock` | `True`, если модель не найдена и показана заглушка |

Приложение ищет модель по путям `models/best_model.pkl`, затем `models/si_model.joblib`. Признаки берутся из `src/features.py` (если файла нет, из `src/si_model.py`).

Если в пакете модели в поле `target` есть `log10`, выход модели возводится в степень 10. Иначе он считается сырым значением SI, а отрицательные значения заменяются нулём.

## Режим заглушки

Если файл модели не найден, приложение всё равно запускается. Вверху появляется предупреждение, а числа SI фиктивные и зависят только от SMILES. Этот режим нужен для разработки интерфейса и не должен показываться на защите.

|------|--------|----------|

## Ограничения

* Отдельного классификатора «активно / неактивно» нет. Статус получен порогом SI ≥ 10 по прогнозу регрессии. Этот порог взят из общепринятой практики и не указан в условиях задачи.
* Разброс деревьев (`std_SI`) показывается только для Random Forest и Extra Trees. Это грубая оценка уверенности, а не доверительный интервал.
* График важности показывает только дескрипторы (последние признаки вектора), а не биты отпечатка Моргана. Для HistGradientBoosting он не строится.
* Приложение показывает метрики из кросс-валидации обучающей выборки. Результат на Kaggle может отличаться.
* Модель является исследовательским прототипом. Прогнозы не заменяют лабораторные эксперименты.
