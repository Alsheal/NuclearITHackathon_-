# Molecular Activity Prediction — VACV

## 1. Описание проекта

Проект разработан в рамках соревнования **Molecular Activity Prediction (Предсказание молекулярной активности)**.

Цель проекта — разработать модель машинного обучения, которая предсказывает индекс селективности (Selectivity Index, SI) химических соединений против вируса Vaccinia (VACV) на основе их молекулярной структуры, представленной в формате SMILES.

Индекс селективности рассчитывается по формуле:

$$
SI = \frac{CC50}{IC50}
$$

где:

* **CC50** — концентрация вещества, вызывающая гибель 50% клеток;
* **IC50** — концентрация вещества, необходимая для подавления активности вируса на 50%.

## 2. Используемые технологии

* Python
* Pandas — обработка таблиц и данных;
* NumPy — математические операции;
* RDKit — обработка химических структур;
* Scikit-learn — машинное обучение;
* Random Forest Regressor — модель регрессии;
* Joblib — сохранение обученной модели.

## 4. Входные данные

Для разработки модели используются предоставленные организаторами CSV-файлы.

**train_v2.csv** — обучающая выборка. Содержит SMILES, характеристики химических соединений и известные значения SI VACV.

**test.csv** — тестовая выборка. Содержит химические соединения, для которых необходимо получить прогноз.

**sample_submit.csv** — пример требуемого формата файла отправки на Kaggle.

## 5. Обработка химических соединений

Для преобразования молекулярных структур в числовые признаки используется библиотека RDKit.

Из SMILES извлекаются:

* Morgan Fingerprints — бинарное представление структуры молекулы;
* молекулярная масса;
* LogP;
* TPSA;
* количество доноров и акцепторов водородных связей;
* количество колец;
* количество вращаемых связей;
* Fraction CSP3;
* количество тяжёлых атомов.

Дополнительно используется CC50 и признак, указывающий на отсутствие этого значения.

Некорректные SMILES обрабатываются отдельно, а пропущенные числовые значения учитываются при подготовке данных.

## 6. Машинное обучение

В качестве основной модели выбран **Random Forest Regressor**.

Random Forest представляет собой ансамбль решающих деревьев. Каждое дерево делает собственный прогноз, после чего результаты объединяются.

Модель выбрана для решения задачи регрессии, поскольку необходимо предсказывать числовое значение SI VACV.

Перед обучением целевая переменная преобразуется с помощью log10. Это позволяет работать со значениями SI, которые могут значительно отличаться по масштабу.

Для обучения:

1. Проверяются и очищаются исходные данные.
2. Исключаются некорректные молекулярные структуры.
3. Исключаются строки с неположительными значениями SI.
4. Данные разделяются на обучающую и проверочную выборки.
5. Выполняется обучение Random Forest.
6. Рассчитываются метрики качества MAE, RMSE и R².
7. Модель переобучается на всех подходящих обучающих данных.

Готовая модель сохраняется с помощью Joblib в `models/si_model.joblib`.

## 7. Получение предсказаний

После обучения запускается `predict.py`.

Скрипт:

1. Загружает тестовые данные.
2. Загружает сохранённую модель.
3. Преобразует SMILES в числовые признаки.
4. Получает прогнозы SI VACV.
5. Возвращает значения из логарифмической шкалы.
6. Формирует итоговый CSV-файл.

Результат сохраняется в:

```text
results/submission.csv
```

Файл содержит два столбца:

* `index` — индекс тестовой записи;
* `SI VACV` — предсказанное значение индекса селективности.

* отсутствие пустых и некорректных предсказаний.

## 11. Итог

В рамках проекта реализована основа конвейера машинного обучения для прогнозирования молекулярной активности против вируса Vaccinia.

Подготовлена обработка химических структур SMILES, извлечение молекулярных признаков, реализация модели Random Forest, обучение и оценка качества, а также формирование файла предсказаний для Kaggle.

Проект организован таким образом, чтобы обучение модели и получение результатов выполнялись отдельными скриптами и могли быть воспроизведены повторно.

# Участник №4 — демонстрационное приложение

## Назначение

Веб-приложение, которое собирает результаты работы команды в одном месте: показывает прогноз индекса селективности SI против вируса осповакцины (VACV) по SMILES, ранжирует список молекул-кандидатов и выводит графики по данным и модели.

Приложение ничего не обучает и не собирает: данные готовят участники №1 и №3, модель обучает участник №2. Приложение читает их готовые файлы. Столбцы `CC50_uM` и `IC50_uM_VACV` в нём не вводятся.

## Вкладки

1. **Прогноз.** Ввод SMILES, примеры молекул, структура (RDKit), прогноз SI и log10(SI), вероятный диапазон (разброс деревьев), статус относительно порога SI ≥ 10, проверка правила пяти Липински, таблица дескрипторов.
2. **Кандидаты (CSV).** Загрузка CSV со столбцом `smiles` (например, список придуманных соединений), ранжирование по прогнозу SI, график лучших, скачивание результата.
3. **Результаты проекта.** Список готовых компонентов, метрики модели, таблица экспериментов, гистограмма прогнозов для теста Kaggle, важность признаков, распределения SI в данных организаторов и во внешнем датасете.

## Какие файлы читает приложение

| Файл | Откуда | Что показывает |
|------|--------|----------------|
| `models/si_model.joblib` | `train.py` (№2) | прогнозы, важность признаков |
| `results/training_report.json` | `train.py` (№2) | метрики модели |
| `results/submission.csv` | `predict.py` (№2) | гистограмма прогнозов для Kaggle |
| `data/train.csv` | организаторы | распределение SI |
| `experiments/results.csv` | все участники | таблица экспериментов |
| `data/external_raw.csv`, `data/final_dataset.csv`, `data/train_chembl.csv` или `train_chembl.csv` | №1 и №3 | статистика внешних данных |

Если какого-то файла нет, соответствующий блок просто не показывается, а на вкладке «Результаты проекта» он отмечен как отсутствующий. Если модели нет, включается режим заглушки с фиктивными числами и предупреждением вверху. Показывать его на защите нельзя.

Признаки молекулы приложение считает функцией `smiles_to_features` из `src/features.py`.
