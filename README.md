## 1. Описание задачи

Цель проекта — разработать модель машинного обучения для предсказания индекса селективности (Selectivity Index, SI) химических соединений в отношении вируса осповакцины (Vaccinia virus, VACV).

В качестве входных данных используется молекулярная структура соединения, представленная в формате **SMILES**.

Индекс селективности определяется следующим отношением:

\[
SI = \frac{CC50}{IC50}
\]

где:

- **CC50** — концентрация вещества, вызывающая гибель 50% клеток;
- **IC50** — концентрация вещества, необходимая для подавления 50% вирусной активности.

Чем выше значение SI, тем более селективным считается соединение.

**Метрика оценки:** Mean Squared Error (MSE). Чем меньше значение метрики, тем точнее предсказания модели.

В соответствии с правилами соревнования значения `CC50_uM` и `IC50_uM_VACV` не используются в качестве признаков или для формирования предсказаний. Модель обучается на официальном целевом столбце `SI VACV`, а все молекулярные признаки извлекаются исключительно из SMILES.

## 3. Подход к решению задачи

### 3.1. Извлечение молекулярных признаков

Для представления химических соединений используются три группы признаков, вычисляемых библиотекой RDKit.

**1. Molecular Descriptors**

Набор молекулярных дескрипторов, характеризующих физико-химические и структурные свойства соединений.

Они позволяют описать молекулу с помощью числовых характеристик, например молекулярной массы, липофильности, количества доноров и акцепторов водородных связей и других параметров.

**2. MACCS Keys**

Бинарные структурные отпечатки, отражающие наличие определённых химических фрагментов и функциональных групп в молекуле.

**3. Morgan Fingerprints**

Молекулярные отпечатки, описывающие локальное химическое окружение атомов.

В проекте используются Morgan fingerprints с радиусом 2 и размерностью 1024. Дополнительно применяются счётчики встречаемости структурных фрагментов.

Таким образом, каждая молекула преобразуется в единый числовой вектор, объединяющий дескрипторы, MACCS keys и Morgan fingerprints.

### 3.2. Обработка целевой переменной

Распределение индекса селективности имеет выраженную асимметрию: в данных присутствуют как небольшие значения SI, так и значительно более высокие значения.

Для стабилизации обучения применяется логарифмическое преобразование:


y = log_{10}(1 + SI)

Это преобразование уменьшает влияние экстремальных значений и позволяет модели эффективнее обучаться на широком диапазоне целевой переменной.

После предсказания выполняется обратное преобразование:

SI_{pred} = 10^{y_{pred}} - 1


Отрицательные предсказания ограничиваются нулём.

### 3.3. Выбор модели

В качестве единственного алгоритма регрессии используется **LightGBM Regressor**.

LightGBM — градиентный бустинг на деревьях решений. Он позволяет работать с нелинейными зависимостями между молекулярными признаками и целевой переменной.

Выбор модели обусловлен следующими факторами:

- способностью учитывать нелинейные зависимости;
- эффективной работой с числовыми признаками;
- возможностью регуляризации;
- сравнительно высокой скоростью обучения;
- возможностью настройки сложности деревьев для небольших наборов данных.

В финальном решении используется одна модель LightGBM, без ансамблирования нескольких алгоритмов.

## 4. Валидация модели

Для оценки качества используется **GroupKFold с пятью фолдами**.

В качестве групп применяются молекулярные скаффолды Murcko, извлекаемые из SMILES.

Такой подход позволяет распределять молекулы со схожими структурными каркасами по одной группе и не допускать попадания одного и того же скаффолда одновременно в обучающую и проверочную части фолда.

Это особенно важно для химических задач: случайное разделение молекул может приводить к завышенной оценке качества из-за структурного сходства соединений.

Для оценки используются:

- **RMSE** — корень из средней квадратичной ошибки;
- **MAE** — средняя абсолютная ошибка;
- **Spearman correlation** — корреляция рангов предсказанных и истинных значений.

Дополнительно рассчитывается ошибка в исходной шкале SI, поскольку именно она соответствует целевой переменной соревнования.

## 5. Проведённые эксперименты

В ходе работы были проверены различные варианты обучения одной модели LightGBM.

### 5.1. Обучение на исходном SI

Первоначально модель обучалась непосредственно на значениях SI.

Результаты кросс-валидации:

| Метрика | Результат |
|---|---:|
| MSE | 4 660 815.53 |
| RMSE | 2 158.89 |
| MAE | 381.84 |
| Spearman | 0.260 |

Прямое обучение на исходной шкале показало недостаточно хорошие результаты. Большие значения SI оказывали существенное влияние на функцию ошибки.

### 5.2. Логарифмическое преобразование SI

Затем было проверено обучение на преобразованной целевой переменной `log10(1 + SI)`.

Этот подход позволил улучшить качество предсказаний по сравнению с обучением на исходной шкале.

В одном из экспериментов получены следующие результаты:

| Метрика | Результат |
|---|---:|
| MSE | 4 285 787.61 |
| RMSE | 2 070.21 |
| MAE | 211.03 |
| Spearman | 0.491 |

## 6. Финальный пайплайн

Решение состоит из двух основных этапов.

### Этап 1. Обучение

1. Загружается официальный обучающий набор `train.csv`.
2. Удаляются строки без SMILES или целевого значения SI.
3. Из SMILES извлекаются молекулярные дескрипторы и отпечатки.
4. Целевая переменная преобразуется по формуле `log10(1 + SI)`.
5. Выполняется пятифолдовая кросс-валидация с группировкой по Murcko-скаффолдам.
6. Модель LightGBM обучается на всей доступной обучающей выборке.
7. Обученная модель сохраняется в `models/si_model.joblib`.

### Этап 2. Предсказание

1. Загружается сохранённая модель.
2. Читается тестовая выборка `test.csv`.
3. Из SMILES извлекаются те же признаки, что и при обучении.
4. Модель предсказывает логарифм индекса селективности.
5. Выполняется обратное логарифмическое преобразование.
6. Формируется `submission.csv` в формате, требуемом соревнованием.

## 7. Установка и запуск

### Установка зависимостей

Для работы проекта необходимо установить зависимости:

```bash
pip install -r requirements.txt
```

В проекте используются основные библиотеки:

- Python
- RDKit
- LightGBM
- NumPy
- Pandas
- scikit-learn
- Joblib

### Обучение модели

Из корневой директории проекта выполните:

```bash
python -m src.train --no-external
```

После завершения обучения модель будет сохранена в:

```text
models/si_model.joblib
```

### Генерация предсказаний

Запустите:

```bash
python -m src.predict
```

В результате будет создан файл:

```text
results/submission.csv
```

Файл содержит два столбца:

```csv
index,SI VACV
0,12.345
1,6.789
```

Фактические значения в файле формируются моделью.

## 9. Ограничения и особенности решения

При разработке учитывались следующие особенности задачи:

- небольшой объём официальной обучающей выборки;
- выраженная асимметрия распределения SI;
- наличие экстремальных значений целевой переменной;
- структурное сходство некоторых молекул;
- необходимость исключить утечку целевой информации.

В качестве признаков используются только характеристики, извлечённые из SMILES. Значения `CC50_uM` и `IC50_uM_VACV` не передаются модели и не используются для получения предсказаний.

В текущем финальном пайплайне внешние данные отключены: обучение проводится на официальной обучающей выборке соревнования.
